# Repository Guide

## Structure
- `dopios_backend/`: Django project configuration.
- `mainApp/`: application code, migrations, and management commands.
- `docs/`: repository reference material; read the relevant document before changing its subject.
- `CONTRIBUTING.md`: coding conventions.

## Development
Use the Docker workflow in `docs/codex_docker_workflow.md` when working with services.

Keep functions focused, use Google-style docstrings, and add migrations for model changes.
